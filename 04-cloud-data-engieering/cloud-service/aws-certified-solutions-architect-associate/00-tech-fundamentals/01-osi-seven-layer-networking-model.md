# OSI model introduction

* The OSI (Open Systems Interconnection) model is a conceptual framework that describes the communication functions of a telecommunication or computer system
* The OSI divided the model into seven layers, each layer is designed to provide standardized approach to network communication, allowing different types of deviced to communicate with each other regardless of their underlying hardware of software

Host: 
Layer 7 - Application
Layer 6 - Presentation
Layer 5 - Session 
Layer 4 - Transport 

Media:
Layer 3 - Network 
Layer 2 - Data Link
Layer 1 - Physical
