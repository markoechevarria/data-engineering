# AWS Service Catalog

* Is a regional service

## Service Catalog

* A service catalog can be thought as a document or database created by an IT team
* Organized collection of products, which are oferred by teams within the business. Traditionally they are created by IT 
* Key product Information: Product Owner, Cost, Requirements, Support Information, Dependancies
* Defines approval of provisioning from IT and Customer side
* Allows manages costs and scale service delivery

## Key features

* Self-Service Portal for 'end users' 
* Users can go and lunch predefined (by admin) products
* End user permissions can be controlled (Roles, Launch Constraints)
* Admins define those products (CloudFormation/Terraform) and the permissions required to launch them
* Build products into portfolios, that is how they are made visible to end users
