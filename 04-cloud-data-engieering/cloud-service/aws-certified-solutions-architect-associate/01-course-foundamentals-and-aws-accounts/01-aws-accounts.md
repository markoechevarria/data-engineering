# AWS accounts - The basics

* An AWS account is a container for identities (users) and resources
* An AWS Account has an account name, and unique email address and a credit card (can be used across multiple aws account)
* The Account Root User is a special user which has full control over all of its AWS account and any resources created within it and can't be restricted
* Additional identities can be created inside the AWS account which can be restricted and granted FULL or LIMITED permissions via IAM (Identity and Access Management)
* AWS accounts can contain the impact of admin errors, or exploits by bad actors. 
* Using separate accounts for separate things (DEV, TEST, PROC) or teams or products or clients is a good practice
* External identities can be granted access to the AWS account
